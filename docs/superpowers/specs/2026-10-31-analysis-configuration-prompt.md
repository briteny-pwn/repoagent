# 分析配置缺失提示

用户要求：缺少配置时弹出浮窗，后续修改使用规范 Git 提交与 PR。

点击“新建分析”与提交“开始分析”均读取最新设置，检查模型名称、模型 API Key、GitHub 目标仓库。GitHub token 不属于只读分析的必填项。

缺失时使用原生模态 dialog 列出具体项，提供“稍后配置”和“前往设置”，支持 Escape 关闭及键盘焦点约束。关闭和跳转不清空已输入问题。读取失败走现有错误提示，不创建任务、不误判缺失；配置完整时沿用创建流程。

验证：配置组合单测、生产构建、浏览器中两个入口、Escape、设置跳转和配置完整路径。通过修复分支提交 PR；现有应用作为空仓库的首次 main 基线。
