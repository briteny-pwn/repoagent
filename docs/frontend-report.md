# 前端交付

实现见 `frontend/`。登录、工作台、任务历史、任务详情、报告证据、草稿审核和四类设置页均连接真实 `/api`。草稿操作传版本号；发布结果不明时没有重试按钮。密钥只以配置标记和密码输入呈现。任务详情每 3 秒轮询。

设置页重新进入会读取最新配置；订阅和节点任务完成时也会刷新。后台更新保留正在编辑的表单，模型连接测试和仓库验证不会清空未保存输入。报告 Markdown 不加载外部图片。

验证：`cd frontend && npm test`，8 项通过；`npm run build` 通过。已用本地 FastAPI 与 Vite 在浏览器验证登录、设置及工作台空状态。尚无真实远程服务凭据，因此未测试模型、GitHub 发布或订阅抓取。
